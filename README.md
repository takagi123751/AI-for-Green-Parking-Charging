# 光储充一体化停车场绿色AI优化策略

> 南通大学第一届 "AI for Green" 人工智能24小时挑战赛 A赛道作品

## 项目简介

针对电动汽车停车场真实场景，构建**微观车辆泊松到达模型**，耦合光伏、储能与充电桩系统，对比基准方案、线性规划、遗传算法、DQN强化学习四种调度策略，实现停车场绿电消纳率、碳排放与综合成本的多目标优化。

## 核心特性

### 真实性提升
- 15分钟精细时间步长，还原真实调度颗粒度
- 车辆泊松到达模型，模拟早晚高峰车流与随机停留时长
- 光伏出力加入天气随机扰动，适配真实工况

### 全维度对比
| 方案类型 | 代表算法 | 特点 |
|---------|---------|------|
| 基准方案 | 无优化 | 车辆即到即充，作为性能下限 |
| 数学规划 | 线性规划(LP) | 全局最优解，作为理论上限 |
| 启发式算法 | 遗传算法(GA) | 工程常用智能算法对比 |
| 人工智能 | DQN强化学习 | 端到端AI决策，适配随机环境 |

### 评价指标
- 日综合成本（电费+碳成本）
- 日碳排放量
- 绿电消纳率
- 光伏弃光率
- 充电桩利用率

## 本核心升级

1. **真实性拉满**：时间步长细化至 15 分钟（96 步/天），采用泊松到达 + 车辆微观模型生成充电负荷，模拟真实停车场早晚高峰车流、车辆停留时长、电池容量差异；光伏出力采用逐 15 分钟典型日曲线，加入天气随机扰动。

2. **对比度扩充**：升级为 4 组全维度对比：无优化基准、线性规划（理论最优上限）、遗传算法（启发式算法）、DQN 强化学习（AI 算法），评价指标覆盖成本、碳排放、绿电消纳率、弃光率、充电桩利用率 5 个维度。

3. **工程化增强**：全模块化拆分，参数统一配置，自动输出多维度对比图表，完全符合 GitHub 开源项目规范。
